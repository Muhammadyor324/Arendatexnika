# ArendaTexnika

Qurilish texnikalarini kunlik ijaraga berish va olish uchun marketplace interfeysi.

## Ishga tushirish

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

## Tayyorlangan modullar

- Bosh sahifa: qidiruv, joylashuv/sana maydonlari, kategoriyalar, tavsiya etilgan texnikalar va "qanday ishlaydi" bloki.
- Katalog: qidiruv, kategoriya, hudud, narx oralig‘i va qo‘shimcha filtrlar; saralash va sevimlilar.
- Texnika sahifasi: galereya, texnik xususiyatlar, kunlik narx, mavjudlik kalendari, egasi, xarita ko‘rinishi, sharhlar va bron qilish.
- Band qilish: sanalar bo‘yicha kunlarni hisoblash, umumiy narx va Payme, Click yoki naqd to‘lov tanlovi.
- Foydalanuvchi kabineti: e’lonlar, buyurtmalar, faoliyat, daromad grafigi, chat va to‘lovlar tarixi.
- E’lon qo‘shish: texnika ma’lumotlari, narx, joylashuv, tavsif va media yuklash interfeysi.
- Admin panel: statistika, daromad grafigi, foydalanuvchilar, e’lonlar, buyurtmalar va moderatsiya navbati.
- Responsive dizayn: mobil, planshet va desktop ekranlar uchun.
- Bildirishnomalar, profil menyusi, autentifikatsiya oynasi va til almashtirish demo holatda.

Hozirgi versiya frontend MVP sifatida local state bilan ishlaydi. Payme/Click, SMS OTP, xarita API, fayl storage va backend ulanishi uchun server/API kalitlari qo‘shilishi kerak.
